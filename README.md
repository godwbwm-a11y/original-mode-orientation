# ORIGINAL MODE — 0. 오리엔테이션

성 카를로 아쿠티스와 함께 걷는 7일 묵상 웹게임의 스마트폰용 오리엔테이션입니다.

## 실행

별도 빌드가 없는 정적 웹게임입니다. 로컬 웹 서버로 이 폴더를 열면 실행됩니다.

```text
HTML5 · CSS3 · Vanilla JavaScript · Phaser 3 CDN · LocalStorage
```

## 조작

- 스마트폰 세로 화면: 왼쪽 아래 이동, 오른쪽 아래 점프·대화 버튼
- 점프 버튼을 공중에서 한 번 더 누르면 더 높이 오르는 2단 점프
- PC: 방향키 또는 A/D로 이동, 위쪽 방향키·스페이스로 점프, E·Enter로 대화
- 진행 내용은 브라우저의 LocalStorage에 자동 저장됩니다.

## 구현 범위

복사본 도시부터 카를로와의 만남, 카를로의 하루 탐색, 복사본 공장, 나의 원본 노트, 알림 달리기, 조용한 성당, 좋은 점 찾기, 위를 바라봐, 7개의 문, 첫 질문, 시작 기도, 엔딩까지 이어지는 0. 오리엔테이션 전체를 포함합니다.

## 배포

`netlify.toml`이 포함되어 있어 프로젝트 루트를 그대로 Netlify에 배포할 수 있습니다.
