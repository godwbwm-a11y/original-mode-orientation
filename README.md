# ORIGINAL MODE — 0. 오리엔테이션

성 카를로 아쿠티스와 함께 걷는 7일 묵상 웹게임의 스마트폰용 오리엔테이션입니다.

## 실행

별도 빌드가 없는 정적 웹게임입니다. 로컬 웹 서버로 이 폴더를 열면 실행됩니다.

```text
HTML5 · CSS3 · Vanilla JavaScript · Phaser 3 CDN · LocalStorage
```

## 조작

- 스마트폰 세로 화면: 왼쪽 아래 이동, 오른쪽 아래 점프·대화 버튼
- 점프 버튼을 공중에서 한 번 더 누르면 더 높이 오르는 2단 점프
- PC: 방향키 또는 A/D로 이동, 위쪽 방향키·스페이스로 점프, E·Enter로 대화
- 진행 내용은 브라우저의 LocalStorage에 자동 저장됩니다.

## 구현 범위

복사본 도시부터 영화식 카를로 만남과 문자 대화, 카를로의 하루 탐색, 축구·협동 빙고·기도문·용돈 모으기 미니게임, ‘나의 하루’ 성찰, 나의 원본 노트, 실제 성당 감실 사진을 바라보는 10초·30초 성체조배, 좋은 점 찾기, 빛을 모으며 오르는 ‘위를 바라봐’, 7개의 묵상 문, 첫 질문, 마침기도, 엔딩까지 이어지는 0. 오리엔테이션 전체를 포함합니다.

엔딩에서는 기록을 지우고 처음부터 다시 플레이할 수 있습니다.

게임 마지막에 사용한 성 카를로 아쿠티스의 ‘원본과 복사본’ 말은 [교황청 보도 자료](https://press.vatican.va/content/salastampa/it/bollettino/pubblico/2025/11/30/0932/01720.html)에 인용된 표현을 한국어로 옮긴 것입니다.
